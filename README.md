# 링크위키 LinkWiki

한국어 이용자를 위한 공개 사이트 주소모음·링크모음·사이트모음입니다. 사이트 이름이나 도메인으로 검색하고, 관심 분야별로 등록된 서비스를 비교할 수 있습니다.

## 직접 이용하기

- [사이트 주소모음 전체 목록 검색·두 사이트 비교](https://linkwiki.info/directory)
- [분야별 링크모음](https://linkwiki.info/categories/)
- [링크위키 홈페이지](https://linkwiki.info/)
- [공식 주소 확인 방법](https://linkwiki.info/guides/address-check)
- [목록 운영과 정보 확인 범위](https://linkwiki.info/about)

현재 공개 목록에는 228개의 사이트 항목이 등록되어 있습니다. 이 숫자는 데이터가 바뀌면 달라질 수 있으며, 각 사이트의 이름·설명·이동 주소는 공개 목록에서 확인할 수 있습니다.

## 안내

링크위키는 외부 사이트의 운영자가 아니며, 등록 링크가 공식 인증·실시간 접속 확인·안전성 검증을 뜻하지 않습니다. 주소가 변경되거나 설명에 오류가 있을 때는 홈페이지에 안내된 운영 문의 경로로 알려주세요. 비밀번호·인증번호 등 민감한 정보는 보내지 마세요.

이 저장소는 링크위키의 별도 공개 SEO 사이트 소스입니다. 링크위키 본 사이트의 관리자 계정·데이터베이스·비공개 운영 시스템과 직접 연결하지 않습니다.

## 개발과 자동 검사

이 저장소의 공개 SEO 페이지는 `build.py`로 정적 빌드되며, GitHub Actions에서 테스트·배포 무결성·Google Search Console 측정 등 읽기 전용 검사를 수행합니다. 자동 테스트 통과는 Google 색인이나 특정 검색어의 순위를 보장하지 않습니다.

## 외부 링크 기록

이 README는 프로젝트 소유자가 작성한 공식 설명입니다. 공개 프로젝트 문서의 링크는 제3자의 독립적인 추천이나 검색엔진의 링크 평가를 뜻하지 않습니다.
