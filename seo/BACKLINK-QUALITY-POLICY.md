# LinkWiki 백링크 확보·검증 운영 기준 (2026-10-28)

대상 URL: https://linkwiki.info/

## 기본 원칙

- 백링크의 목적은 실제 사용자가 사이트를 발견하도록 돕는 것이다. 검색 순위 조작 목적의 대량 등록, 링크 교환, 유료 링크 구매는 진행하지 않는다.
- 기존 `seo/backlink-registry.json`의 동일 플랫폼/제출 URL 기록을 먼저 확인한다. 제출 완료·심사 대기 항목은 재제출하지 않는다.
- 등록처의 공식 정책과 사이트 주제의 적합성을 확인한다. 링크만을 위한 저품질 디렉터리, 불명확한 심사·출처, 과도한 광고 페이지는 제외한다.
- 공식 문서에 등록 API와 사용 권한이 명확하게 있는 경우에만 API 연동을 별도로 검토한다. 임의 폼 호출·CAPTCHA 우회·계정 대량 생성·자동 댓글/게시물 등록은 금지한다.
- 제출 전 사람에게 보이는 소개문에 서비스의 실제 기능과 필요한 NSFW/성인 관련 분류·제한 사항을 정확하게 기재한다. `linkwiki01.com`을 외부 홍보 URL로 사용하지 않는다.
- 링크 텍스트는 브랜드명 또는 자연스러운 설명으로 한다. 반복적인 검색 키워드 앵커를 강제하지 않는다.
- 공개 URL과 실제 HTML 링크가 확인되기 전에는 '검증된 백링크'로 집계하지 않는다. `nofollow`, `ugc`, `sponsored`, `noindex` 상태를 함께 기록한다.
- 기존 SEO 글 발행과 Search Console 모니터링 일정은 변경하지 않는다.

## 등록 의사결정 체크리스트

1. **중복 확인:** `seo/backlink-registry.json`에 같은 도메인/서비스와 과거 제출 이력이 있는가?
2. **적합성:** 해당 플랫폼의 독자가 LinkWiki의 사이트 탐색 기능을 실제로 필요로 할 가능성이 있는가? 사이트 정책상 허용되는가?
3. **비용:** 무료 경로가 명확한가? 등록을 위해 유료 업그레이드·배지·링크 교환을 요구하면 제외한다.
4. **제출 수단:** 공식 API와 허용 범위가 명확한가? 아니라면 수동 심사 대상으로만 남긴다.
5. **내용:** 홈 URL 한 번만 제출하고, 사실에 맞는 고유 설명 및 적절한 카테고리를 사용한다.
6. **증거:** 제출 확인, 심사 상태, 승인 메일, 공개 URL을 구분해 저장한다.
7. **공개 검증:** `python3 seo/backlink_manager.py audit --limit 30`으로 공개 링크를 확인한다.

## 측정과 중단 조건

- **성과 지표:** 새로 확인된 공개 링크 URL 수, 링크 상태, 해당 사이트의 실제 추천 방문, Search Console 장기 지표.
- **중단:** 부적합/불명확한 사이트, 유료 요구, CAPTCHA, 정책 위반 가능성, 과도한 중복·반복 제출.
