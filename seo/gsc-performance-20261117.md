## 사이트맵·크롤링 상태

- 공개 `https://linkwiki.info/sitemap.xml`: 56개 URL, 모두 extensionless canonical 형식으로 라이브 검증됨.
- 공개 사이트맵의 최신 명시적 수정일: 2026-11-17.
- 2026-11-17 GSC 제출 작업 로그: canonical `sitemap.xml`은 Google 처리 대기(`isPending`) 상태여서 중복 제출을 건너뜀. 제출 대기와 Google 다운로드·색인 완료는 서로 다르다.
- Search Console 연결 데이터에 노출된 기존 `sitemap-v2.xml` 기록: 49개 제출, 색인 0, 마지막 다운로드 2026-11-12, 오류 0, 경고 0. 이 값은 기존 v2 제출 기록이며 최신 canonical `sitemap.xml`의 처리 결과로 해석하면 안 된다.
- `sitemap-v2.xml`은 공개 canonical sitemap과 같은 URL 집합을 제공하는 레거시 경로다. canonical sitemap 처리 완료 전에는 기존 경로를 섣불리 제거하지 않는다.

## 다음 우선순위

1. Google이 pending 상태인 canonical `sitemap.xml`을 실제로 다운로드했는지 확인한다.
2. 처리 이후 `/directory`, 카테고리 허브 및 13개 카테고리의 URL Inspection 저장 상태를 확인한다.
