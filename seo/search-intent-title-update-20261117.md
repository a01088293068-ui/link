# 검색 결과 제목·목록 페이지 의도 정리 — 2026-11-17

## 관찰

- Google 검색 결과의 공개 스니펫에 과거 `228개 사이트` 제목·설명이 남아 있다.
- 현재 운영 페이지와 저장소 빌드 결과는 360개 사이트를 제공한다.
- 최근 28일 국내 Search Console 페이지 보고서에서는 홈페이지 URL만 노출 행으로 반환됐다. 다른 URL의 색인 여부를 이 사실만으로 단정하지 않는다.
- 공개 `/directory`는 자체 canonical, `index,follow`, 사이트맵 등록 상태다.

## 변경

- 홈페이지는 기존대로 `주소모음·링크모음·사이트모음` 핵심 검색어 허브로 유지한다.
- 전체 목록은 `사이트모음 전체 목록`이라는 독립 검색 의도를 명확히 하도록 제목과 H1을 정리한다.
- 제목은 `사이트모음 전체 목록 | 360개 사이트 검색·비교 - 링크위키` 형태로 구성하고, description에는 이름·도메인·분야별 검색 및 설명·주소 비교 기능을 구체적으로 기술한다.
- 홈과 전체 목록이 같은 제목을 반복하지 않도록 기존 검색 의도 분리 원칙을 유지한다.

## 검증 원칙

- 빌드 결과의 title, H1, description, OG title이 동일한 목록 의도를 반영하는지 테스트한다.
- Google 검색 결과 반영은 별도 Search Console URL Inspection 및 실제 검색 결과 재확인 전까지 완료로 간주하지 않는다.
- 제목 변경만으로 순위 상승을 보장하지 않는다.
