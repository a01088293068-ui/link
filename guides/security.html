로그인·결제·파일 다운로드 전에 위험 신호를 확인하세요.

접속 전 30초 점검

주소 철자와 도메인을 확인하고, 갑작스러운 비밀번호·인증번호 입력 요구 또는 설치 파일 요청이 있는지 살펴보세요. HTTPS 표시만으로 사이트가 안전하다고 단정할 수는 없습니다.

핵심 요약

주소가 열리고 HTTPS가 표시되더라도 안전성이 보장되는 것은 아닙니다. 로그인·결제·다운로드 전에는 도메인, 운영 주체, 요청 권한을 각각 확인하세요.

접속 전에 확인할 4가지

  1. 주소와 운영 주체: 서비스가 직접 안내한 공식 주소와 철자·도메인 끝부분을 비교하세요. 검색 광고의 제목만 믿고 접속하지 마세요.
  2. 로그인 정보: 예상하지 못한 비밀번호 재입력, 인증번호 전달, 복구 코드 제출을 요구하면 입력을 멈추세요.
  3. 결제와 설치: 별도 앱 설치나 송금을 먼저 요구하는 경우 서비스 공식 안내와 일치하는지 확인하세요.
  4. 파일 다운로드: 압축 파일·실행 파일·브라우저 확장 프로그램을 내려받기 전 출처와 필요성을 검토하세요.

위험 신호별 대응 방법

인증번호나 복구 코드를 메신저로 요청전달하지 말고 해당 서비스 공식 지원 채널로 문의

주소 오류와 보안 위험은 다릅니다

사이트가 열리지 않는다고 해서 반드시 위험한 사이트는 아닙니다. 일시적인 서버 장애, 잘못 입력한 주소, 서비스 이전 등 여러 원인이 있을 수 있습니다. 먼저 사이트 접속 오류 해결 순서를 확인하고, 주소 자체가 의심스럽다면 공식 주소 확인 방법을 살펴보세요.

자주 묻는 질문

HTTPS 자물쇠가 있으면 안전한 사이트인가요?

아니요. HTTPS는 통신 암호화 여부를 나타내며, 사이트 운영자의 신뢰성이나 콘텐츠 안전성을 보장하지 않습니다.

링크모음에 등록된 사이트는 모두 검증된 곳인가요?

아니요. 링크 목록에 실렸다는 사실만으로 안전성이 보증되지는 않습니다. 민감한 정보를 입력하기 전에는 개별 사이트의 공식 안내를 확인하세요.
