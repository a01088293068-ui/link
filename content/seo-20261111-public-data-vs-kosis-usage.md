# 공공데이터포털과 KOSIS 차이: 파일·API와 국가통계표

프로그램에서 쓸 파일이나 API가 필요하면 공공데이터포털을, 인구처럼 지역·시점별 공식 집계표가 필요하면 KOSIS를 먼저 살펴보세요.

## 하려는 일에 맞는 사이트

| 사용 목적 | 출발점 | 확인할 기준 |
|---|---|---|
| 프로그램에서 분석할 파일·API | [공공데이터포털](https://www.data.go.kr/) | 파일 포맷·라이선스·갱신일 |
| 지역·기간별 공식 집계표 | KOSIS | 조사 대상·통계 단위·기간 |
| 여러 기관 데이터 결합 | 제공 기관별 원본 자료 | 단위 통일·누락·중복 |
| 보고서에 수치 인용 | 출처가 명확한 원문 | 표 제목·기관·발표 시점 |

링크위키 등록 목록에서 이름과 도메인을 확인할 수 있습니다. [공공데이터포털 검색 결과](/directory?q=%EA%B3%B5%EA%B3%B5%EB%8D%B0%EC%9D%B4%ED%84%B0%ED%8F%AC%ED%84%B8) · [국가통계포털 KOSIS 검색 결과](/directory?q=%EA%B5%AD%EA%B0%80%ED%86%B5%EA%B3%84%ED%8F%AC%ED%84%B8%20KOSIS)

공공기관 데이터를 찾을 때 숫자만 필요할 수도 있고, 직접 분석할 파일이나 API가 필요할 수도 있습니다. 목적이 다르면 검색을 시작할 곳도 달라집니다. 링크위키에 등록된 공공데이터포털과 국가통계포털 KOSIS를 비교하면서, 자료 형식·제공 기관·갱신 시점이라는 세 가지 기준으로 필요한 정보를 찾는 방법을 정리합니다.

## 먼저 결과물의 형태를 결정합니다

공공데이터포털은 기관이 개방한 파일 데이터와 API 등을 찾아볼 수 있는 서비스로 등록돼 있습니다. 개발 환경에 연결할 자료나 원본 파일을 찾는다면 데이터의 제공 형식과 이용 조건을 먼저 확인하세요. 동일한 주제라도 파일 단위로 나뉘거나 기관별로 공개 범위가 다를 수 있습니다.

KOSIS는 통계표를 항목과 기간별로 탐색할 수 있는 서비스로 등록돼 있습니다. 이미 집계된 인구·경제·사회 지표를 비교하려는 경우에는 통계표의 단위, 조사 기준, 기준 연도 등을 먼저 읽는 방식이 적합할 수 있습니다.

## 자료가 다르면 비교도 달라집니다

같은 인구 관련 숫자라도 서로 다른 조사 방식이나 기간이 사용되면 직접 비교하기 어렵습니다. 표 제목이 비슷해도 '시점', '대상 지역', '단위'를 확인하지 않으면 결론이 달라질 수 있습니다. 숫자를 얻는 것보다 숫자가 무엇을 뜻하는지 명확하게 기록하는 편이 중요합니다.

원자료를 내려받아 직접 계산한다면 결측치·중복 레코드·집계 기준을 확인해야 합니다. 통계표를 그대로 인용할 때에도 작성 기관과 발표 시점을 함께 남기면 다른 사람이 결과를 재검증할 수 있습니다.

## 파일 데이터와 통계표 중 선택하기

[공공데이터포털 검색](/directory?q=%EA%B3%B5%EA%B3%B5%EB%8D%B0%EC%9D%B4%ED%84%B0%ED%8F%AC%ED%84%B8)과 [KOSIS 검색](/directory?q=%EA%B5%AD%EA%B0%80%ED%86%B5%EA%B3%84%ED%8F%AC%ED%84%B8%20KOSIS)에서 현재 링크위키 등록 설명을 각각 확인할 수 있습니다. 목록에서 이름을 확인한 후 공식 페이지에서 제공 형식과 최신 갱신 기록을 점검하세요.

개별 파일이 특정 용도로 가공된 자료인지, 법적 근거가 있는 공식 통계인지 명확히 구분해야 합니다. 한 플랫폼에 자료가 없다고 하여 해당 주제의 공공자료가 존재하지 않는다고 단정하면 안 됩니다.

## 확인한 사실과 미확인 부분

2026년 11월 11일 링크위키 등록 데이터에서 공공데이터포털은 파일 데이터와 오픈 API 탐색, KOSIS는 공식 통계표의 주제·기간별 조회를 제공하는 것으로 설명돼 있었습니다. 공개된 목록 설명에 근거한 비교이며 각 서비스에 로그인하거나 파일을 대량 내려받아 직접 품질을 측정한 실험은 아닙니다.

최신 데이터 제공 주기, API 호출 제한과 실제 다운로드 가능 여부는 제공 기관의 개별 안내에 따라 달라집니다. 링크위키의 안내는 어디서 시작할지 고르는 용도로 이용하고 실제 인용 전에는 원자료의 출처를 확인하세요.

## 자주 묻는 질문

### 두 사이트의 숫자가 다르면 어느 쪽이 틀린 건가요?

기간, 조사 대상, 집계 방식 또는 수정 시점이 다를 수 있습니다. 먼저 같은 정의와 같은 시점의 숫자인지 확인하세요. 이름만 비슷한 자료를 곧바로 합치면 안 됩니다.

### 공공데이터포털의 API는 누구나 제한 없이 쓸 수 있나요?

제공 기관과 데이터셋에 따라 인증·호출량·이용 조건이 달라질 수 있습니다. 실제 사용 전 데이터셋별 공식 문서에서 조건을 확인하세요.

### KOSIS 통계표를 보고서에 인용하려면 무엇을 기록하나요?

통계명, 작성 기관, 대상 기간, 단위, 조회 날짜 등 필요한 정보를 원문과 함께 확인하세요. 해당 지표가 최신 값인지도 별도로 검토해야 합니다.
