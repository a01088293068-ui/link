# 주소모음 검색 결과가 없을 때: 이름·띄어쓰기·도메인으로 다시 찾는 순서

주소모음에서 분명히 알고 있는 사이트를 검색했는데 결과가 없다면 주소가 사라졌다고 바로 결론 내리기 어렵습니다. 검색어와 등록 정보가 맞지 않거나, 아직 목록에 등록되지 않았을 수 있습니다. 링크위키는 인터넷 전체를 검색하는 서비스가 아니라 등록된 사이트 이름, 도메인, 설명을 찾는 목록입니다. 먼저 [전체 주소모음 검색](/directory)에서 어떤 정보를 알고 있는지 확인해 보세요.

## 이름을 알고 있는데 결과가 없는 경우

사이트 이름에는 띄어쓰기와 공식 표기, 약칭이 섞여 있습니다. 이름을 정확히 기억한다면 전체 문구로 검색해 보고, 나오지 않을 때는 핵심 단어만 남겨 보세요. 한글과 영문으로 서로 다른 브랜드 표기가 있는 서비스도 있습니다. 다만 검색어를 너무 짧게 줄이면 같은 단어가 들어가는 무관한 결과가 늘어날 수 있습니다.

예를 들어 웹툰을 찾는다면 플랫폼 이름만 입력하는 것과 '웹툰'이라는 분야를 입력하는 결과는 다를 수 있습니다. 특정 작품을 검색하는 기능을 기대했다면 플랫폼의 공식 검색이 더 적합합니다. 링크위키의 [만화·웹툰 분야 목록](/categories/webtoon)은 작품별 데이터베이스가 아니라 서비스별 출발점을 모아 둔 곳입니다.

## 도메인을 알고 있는 경우

주소 전체를 복사해 입력하면 경로, 검색 매개변수, 추적 코드가 포함될 수 있습니다. 이 경우 먼저 도메인 부분을 읽어 보세요. 예를 들어 `https://example.org/news?ref=mail`에서 호스트는 `example.org`이고 `/news`는 하위 경로입니다. 도메인에 붙은 다른 단어가 공식 서비스와 유사하더라도 운영 주체가 동일하다는 뜻은 아닙니다.

검색 결과에 나타난 링크의 도메인은 반드시 방문 전 확인하고, 로그인이나 결제 화면으로 이동하면 해당 서비스의 공식 안내와 대조하세요. 주소를 확인하는 기준은 [공식 사이트 주소 확인 가이드](/guides/address-check)에서 더 자세히 볼 수 있습니다. HTTPS 여부만으로 사이트 운영 주체를 확인할 수는 없습니다.

## 분야만 알고 있는 경우

서비스 이름이 생각나지 않으면 검색어를 억지로 만들지 말고 목적에 맞는 분야로 이동하는 편이 빠릅니다. [분야별 사이트모음](/categories/)에서는 주제별로 등록된 서비스를 볼 수 있습니다.

- 자료나 장소를 찾으려면 [검색·포털 목록](/categories/search)에서 검색, 지도, 공공자료 서비스를 구분해 봅니다.
- 경기 일정과 통계를 찾으려면 [스포츠 목록](/categories/sports)을 살펴봅니다. 경기 중계 가능 여부는 별개입니다.
- 문서 작성이나 코딩을 도와주는 서비스를 찾으려면 [AI 도구 목록](/categories/ai)에서 작업 목적과 서비스 이용 조건을 비교합니다.
- 커뮤니티에서 의견을 보려면 [커뮤니티 목록](/categories/community)에서 관심 주제와 가입 조건을 확인합니다.

분야별 목록에 없다고 해당 서비스가 폐쇄된 것은 아닙니다. 등록 여부와 실제 운영 상태는 서로 다릅니다.

## 검색어를 바꾼 뒤 확인할 네 가지

첫째, 찾으려는 것이 사이트 이름인지 콘텐츠 제목인지 구분합니다. 둘째, 이름이 아닌 도메인 일부로 확인할 수 있는지 살펴봅니다. 셋째, 동일 목적의 다른 서비스를 먼저 비교해 봅니다. 넷째, 검색 결과가 나타난 경우 표시된 이름과 방문 주소가 같은 운영 주체를 가리키는지 검토합니다.

사이트가 검색되지만 열리지 않는 상황은 별도 문제입니다. 브라우저 캐시, 주소 변경, 접속 제한, 일시적인 서비스 장애가 원인일 수 있습니다. 주소를 추측해 반복 접속하기보다 [링크 접속 오류 해결 안내](/guides/link-troubleshooting)를 확인하세요.

## 검색 결과 0건은 무엇을 의미하나요?

링크위키에 그 검색어와 맞는 등록 항목이 없다는 뜻입니다. 공식 서비스의 존재 여부, 페이지의 삭제 여부 또는 현재 접속 가능 여부를 증명하지 않습니다. 검색 결과 숫자도 인기 순위나 실시간 검증 결과가 아닙니다.

한 번 더 찾아보려면 [주소모음·링크모음 전체 검색](/directory)에서 이름 또는 도메인을 입력하거나 [카테고리별 사이트모음](/categories/)으로 이동하세요. 검색어를 수정해도 찾을 수 없으면 해당 서비스의 공식 안내 경로를 이용해 주소를 확인하는 것이 안전합니다.
