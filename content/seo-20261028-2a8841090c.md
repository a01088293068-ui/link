# 주소모음 검색 결과에서 두 사이트 비교하기: 설명과 도메인 확인법

검색으로 후보를 찾았다면 링크위키 [두 사이트 직접 비교](/directory#directory-two-site-compare)에서 이름, 분야, 등록 설명, 도메인을 나란히 볼 수 있습니다. 검색어를 정하거나 후보를 찾는 단계라면 [검색 실전 가이드](/blog/seo-20261111-address-directory-search-examples/)의 예시부터 살펴보세요.

## 검색에서 고른 두 사이트를 비교하는 순서

1. 검색 결과 카드에서 첫 번째 사이트의 ‘비교에 담기’를 누릅니다.
2. 두 번째 사이트를 다시 검색하고 같은 버튼을 누릅니다. 검색어를 바꿔도 앞서 고른 사이트는 유지되며, 두 번째를 고르면 비교 결과로 이동합니다.
3. 비교 결과에서 분야와 설명을 먼저 읽고, 원하는 서비스의 등록 도메인을 확인한 뒤 사이트를 엽니다.

후보의 이름을 이미 알고 있다면 [두 사이트 직접 비교](/directory#directory-two-site-compare)의 선택 목록에서 각각 고른 뒤 ‘두 사이트 비교하기’를 눌러도 됩니다.

예를 들어 공공서비스 두 곳을 비교할 때 정부24와 국민신문고를 선택하면 각각 어떤 업무에 쓰이는지 등록 설명으로 확인할 수 있습니다. 증명서와 민원·제안 창구를 더 자세히 구분하려면 [정부24와 국민신문고 비교 가이드](/blog/seo-20261111-gov24-epeople-complaint-certificate/)를 참고하세요.

## 비교 결과에서 무엇을 읽으면 되나요?

| 확인할 항목 | 비교할 때 볼 것 |
|---|---|
| 서비스명과 분야 | 같은 이름을 쓰는 다른 서비스가 있는지 확인합니다. |
| 등록 설명 | 두 후보가 실제로 어떤 일을 돕는지 확인합니다. |
| 등록 도메인 | 이동하려는 운영처의 공식 안내에 나오는 도메인과 대조합니다. |

비교 화면은 링크위키 등록 정보를 보여줍니다. 이용 요금, 회원가입 조건, 제공 범위는 각 운영 사이트의 최신 안내에서 확인하세요. 비슷한 도메인 두 개 중 어디가 운영처인지 확인해야 한다면 [공식 주소 확인 방법](/guides/address-check)을 참고할 수 있습니다.

## 링크위키의 두 사이트 비교 기능은 이렇게 작동합니다

검색 결과에서 후보 두 곳을 골랐다면 각 카드의 **비교에 담기**를 이용할 수 있습니다. 첫 번째 사이트를 선택한 다음 다른 후보를 선택하면 두 항목의 등록 정보가 나란히 표시됩니다. 검색어를 바꾸거나 분야를 이동해도 비교할 후보를 다시 찾을 수 있으며, 목록 아래의 비교 영역에서 두 사이트를 직접 선택하는 방법도 있습니다.

비교 결과에는 다음 네 가지 정보가 표시됩니다.

| 비교 항목 | 확인할 내용 | 주의할 점 |
|---|---|---|
| 서비스명 | 내가 찾던 서비스와 이름이 일치하는지 | 이름이 같거나 비슷한 다른 서비스가 있을 수 있습니다. |
| 분야 | 두 항목이 같은 목적의 서비스인지 | 같은 분야로 분류되어도 기능이 완전히 같다는 뜻은 아닙니다. |
| 등록 도메인 | 실제 이동할 웹 주소의 호스트 | 링크위키 등록 주소이며 공식 인증 표시는 아닙니다. |
| 등록 설명 | 어떤 용도로 소개된 사이트인지 | 요금·가입 조건·세부 기능은 운영 사이트에서 확인해야 합니다. |

예를 들어 정부24와 국민신문고를 함께 비교하면 두 서비스가 모두 공공서비스로 탐색되더라도 등록 설명과 연결 도메인을 각각 확인할 수 있습니다. 증명서 발급이 필요한지, 민원이나 정책 제안을 접수하려는지에 따라 실제로 방문할 곳을 구분하는 데 도움이 됩니다. 두 서비스의 담당 업무와 신청 조건은 각 기관의 최신 안내를 기준으로 판단하세요.

### 비교 결과를 읽을 때 놓치기 쉬운 점

- **분야가 같다고 기능이 같은 것은 아닙니다.** 같은 카테고리는 탐색을 위한 분류이며 서비스 간 제휴나 운영 주체의 동일성을 의미하지 않습니다.
- **도메인이 표시된다고 공식 주소가 확인된 것은 아닙니다.** 로그인·결제 전에는 서비스 운영자의 공식 홈페이지나 공지에서 같은 주소를 안내하는지 대조하세요.
- **설명은 등록 정보입니다.** 현재 가격, 무료 체험, 지원 국가, 이용 가능 시간처럼 바뀔 수 있는 정보는 각 서비스의 최신 안내에서 확인해야 합니다.
- **비교는 인기 순위가 아닙니다.** 방문자 수, 이용자 평가, 보안 검사, 실시간 접속 여부를 측정하거나 점수를 매기지 않습니다.

비교 결과 아래의 **이 비교의 링크 열기**를 사용하면 선택한 두 항목을 포함한 주소를 다시 열 수 있습니다. 링크를 공유할 때는 상대방도 해당 사이트 목록이 제공되는 환경에서 결과를 확인할 수 있는지 살펴보세요. 선택한 항목이 목록에서 빠졌거나 주소가 변경된 경우에는 전체 목록에서 두 사이트를 다시 선택하면 됩니다.

비교 기능을 사용하기 전에 후보를 찾는 방법부터 확인하려면 [주소모음 검색 실전 가이드](/blog/seo-20261111-address-directory-search-examples/)를, 두 서비스가 실제 공식 주소인지 검토하려면 [공식 주소 확인 방법](/guides/address-check)을 참고하세요. [두 사이트 비교 화면 바로가기](/directory#directory-two-site-compare)에서 등록 항목을 직접 선택할 수 있습니다.

## 검색·비교 중 막혔을 때

- 같은 사이트를 두 번 선택했다면 한쪽을 다른 후보로 바꿔 주세요.
- 비교할 후보를 아직 못 찾았다면 [전체 사이트 검색](/directory)에서 서비스명을 입력해 보세요.
- 이동한 사이트가 열리지 않으면 [접속 오류 점검 안내](/guides/link-troubleshooting)에서 오류별 확인 순서를 살펴보세요.
