# 주소모음 검색 결과에서 두 사이트 비교하기: 설명과 도메인 확인법

검색으로 후보를 찾았다면 링크위키 [두 사이트 직접 비교](/directory#directory-two-site-compare)에서 이름, 분야, 등록 설명, 도메인을 나란히 볼 수 있습니다. 검색어를 정하거나 후보를 찾는 단계라면 [검색 실전 가이드](/blog/seo-20261111-address-directory-search-examples/)의 예시부터 살펴보세요.

## 검색에서 고른 두 사이트를 비교하는 순서

1. 검색 결과 카드에서 비교하고 싶은 두 사이트의 이름을 확인합니다.
2. [두 사이트 직접 비교](/directory#directory-two-site-compare)에서 첫 번째와 두 번째 사이트를 각각 선택합니다.
3. 비교 결과에서 분야와 설명을 먼저 읽고, 원하는 서비스의 등록 도메인을 확인한 뒤 사이트를 엽니다.

예를 들어 공공서비스 두 곳을 비교할 때 정부24와 국민신문고를 선택하면 각각 어떤 업무에 쓰이는지 등록 설명으로 확인할 수 있습니다. 증명서와 민원·제안 창구를 더 자세히 구분하려면 [정부24와 국민신문고 비교 가이드](/blog/seo-20261111-gov24-epeople-complaint-certificate/)를 참고하세요.

## 비교 결과에서 무엇을 읽으면 되나요?

| 확인할 항목 | 비교할 때 볼 것 |
|---|---|
| 서비스명과 분야 | 같은 이름을 쓰는 다른 서비스가 있는지 확인합니다. |
| 등록 설명 | 두 후보가 실제로 어떤 일을 돕는지 확인합니다. |
| 등록 도메인 | 이동하려는 운영처의 공식 안내에 나오는 도메인과 대조합니다. |

비교 화면은 링크위키 등록 정보를 보여줍니다. 이용 요금, 회원가입 조건, 제공 범위는 각 운영 사이트의 최신 안내에서 확인하세요. 비슷한 도메인 두 개 중 어디가 운영처인지 확인해야 한다면 [공식 주소 확인 방법](/guides/address-check)을 참고할 수 있습니다.

## 검색·비교 중 막혔을 때

- 같은 사이트를 두 번 선택했다면 한쪽을 다른 후보로 바꿔 주세요.
- 비교할 후보를 아직 못 찾았다면 [전체 사이트 검색](/directory)에서 서비스명을 입력해 보세요.
- 이동한 사이트가 열리지 않으면 [접속 오류 점검 안내](/guides/link-troubleshooting)에서 오류별 확인 순서를 살펴보세요.
