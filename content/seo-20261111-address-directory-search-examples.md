# 주소모음 검색 실전 가이드: 사이트 이름·도메인·이용 목적에 맞게 찾는 방법

주소모음을 열었는데 어떤 검색어를 입력해야 할지 모르겠다면, 먼저 알고 있는 정보가 사이트 이름인지, 도메인인지, 필요한 업무인지 구분해 보세요. 같은 사이트를 찾더라도 입력 방식에 따라 결과를 확인하는 과정이 달라집니다. 링크위키의 주소모음은 여러 분야의 등록 사이트를 이름과 주소, 설명으로 살펴보는 목록입니다. 검색 결과가 나타나더라도 링크가 공식 운영처의 인증을 받았다는 뜻은 아닙니다.

[링크위키 전체 주소모음 검색](/directory)에서 실제 등록 사이트를 확인할 수 있습니다. 아래 사례는 현재 목록에 실린 사이트를 기준으로 정리했습니다.

## 1. 사이트 이름을 아는 경우: 정확한 이름부터 검색

이름을 알고 있다면 추측한 주소를 브라우저에 직접 입력하기보다 목록 검색에서 이름과 연결 도메인을 같이 확인하는 편이 편리합니다.

예를 들어 정부 민원 안내를 찾는다면 [정부24 검색 결과](/directory?q=%EC%A0%95%EB%B6%8024)를 열어 등록 설명과 실제 연결 주소를 볼 수 있습니다. 국민신문고는 같은 공공 분야이지만 민원·제안의 접수 창구입니다. 증명서 발급과 민원 접수를 동일한 서비스로 생각하지 않도록 주의하세요. [국민신문고 검색 결과](/directory?q=%EA%B5%AD%EB%AF%BC%EC%8B%A0%EB%AC%B8%EA%B3%A0)도 따로 확인할 수 있습니다.

서비스 이름을 정확히 기억하지 못한다면 분야별 목록을 먼저 열고 화면에 표시된 이름을 확인하세요. 검색어를 여러 번 바꾸는 것보다 빠를 수 있습니다.

## 2. 도메인 일부를 아는 경우: 호스트 이름을 확인

검색 결과에 나타난 사이트 이름만으로는 연결 주소를 확인할 수 없습니다. 특히 주소에 익숙한 브랜드명이 들어가더라도 그 브랜드가 직접 관리하는 주소라는 의미는 아닙니다. 도메인의 글자 순서와 최상위 도메인을 함께 보세요.

예를 들어 `map.naver.com`은 네이버 지도와 관련된 도메인이고, `www.gov.kr`은 정부24에서 사용하는 주소입니다. 그렇지만 비슷한 이름을 섞은 다른 도메인도 만들 수 있습니다. 로그인을 요구한다면 서비스 운영자의 공식 채널에서 최종 주소를 대조하는 것이 좋습니다.

주소를 복사했다면 검색창에 그대로 붙여넣어 보세요. 예를 들어 [중고나라 카페 주소로 검색](/directory?q=cafe.naver.com%2Fjoonggonara%2F%3Futm_source%3Dexample)하면 주소 앞에 `https://`가 없거나 뒤에 공유용 매개변수가 붙어 있어도 등록된 카페 항목을 찾을 수 있습니다. 같은 도메인을 쓰는 다른 카페와 구분할 때는 도메인 뒤의 경로까지 입력하세요.

링크위키의 [주소 확인 안내](/guides/address-check)에는 실제 호스트 부분을 읽는 순서가 정리되어 있습니다. HTTPS 표시만으로 신뢰성을 확정하지 않는 것도 중요합니다.

## 3. 업무만 아는 경우: 먼저 분야를 좁히기

‘세금 내는 사이트’처럼 목적만 기억난다면 서비스 이름부터 억지로 추정하지 마세요.

- 국세 신고·납부 관련 업무를 찾는다면 국세청 홈택스의 공식 안내를 확인합니다.
- 지방세 신고·납부 관련 업무라면 위택스의 담당 범위와 신청 조건을 확인합니다.
- 취업 지원 제도와 채용 정보는 고용24, 학자금·장학금 정보는 한국장학재단에서 확인합니다.
- 학교 공시 정보를 살펴보려면 학교알리미를, 고교 학습 강좌는 EBSi를 먼저 확인합니다.

이 사이트들은 링크위키의 [검색·포털 분야 목록](/categories/search)에 등록되어 있습니다. 목록은 이동 경로를 찾기 위한 자료이므로 실제 신청 가능 여부, 업무 운영 시간, 신청 기한은 해당 기관의 최신 공지를 확인해야 합니다.

## 4. 같은 단어가 여러 서비스를 가리키는 경우

‘지도’라고만 검색하면 장소를 찾는 지도 서비스와 교통 정보를 보여주는 사이트가 함께 떠오를 수 있습니다. 장소·길찾기가 목적이라면 네이버 지도나 카카오맵을 비교하고, 서울 도로 통제·소통을 확인하려는 목적이라면 서울시 교통정보 TOPIS의 안내가 더 적합할 수 있습니다.

‘스포츠’ 역시 경기 결과를 보려는 것과 실제 중계를 보려는 목적이 다릅니다. KBL·NBA 공식 사이트는 일정 및 기록을 확인하는 경로이고, 영상 시청 가능 여부는 별도의 중계권·지역·이용 조건에 따라 달라집니다. [스포츠 분야 목록](/categories/sports)과 [영상·OTT 분야 목록](/categories/video)을 구분해서 살펴보세요.

## 5. 검색 결과가 없다면 확인할 점

첫째, 한글 사이트명에 띄어쓰기나 약칭 차이가 있는지 살펴보세요. 둘째, 사이트 전체 주소를 통째로 붙여넣었다면 불필요한 경로·검색 파라미터를 제외한 도메인 부분으로도 찾아보세요. 셋째, 목록에 등록되지 않은 사이트일 수 있으므로 결과가 없다고 실제 서비스가 존재하지 않는다고 판단해서는 안 됩니다.

목록 검색은 등록된 항목을 탐색하는 기능이지 전체 인터넷을 검색하는 일반 검색엔진이 아닙니다. 어떤 페이지가 열리지 않는다면 주소 변경, 접속 정책, 일시적 장애, 브라우저 문제를 구분해야 합니다. [링크 접속 문제 해결 가이드](/guides/link-troubleshooting)를 참고할 수 있습니다.

## 주소모음, 링크모음, 사이트모음은 어떻게 함께 사용하나요?

주소모음은 이름이나 도메인을 기준으로 사이트를 찾는 데, 링크모음은 관심 분야의 후보를 좁히는 데, 사이트모음은 각 서비스가 제공하는 기능과 이동 주소를 비교하는 데 유용합니다. 세 표현은 실제 이용 과정에서 겹치지만, ‘무엇을 알고 있는지’에 따라 출발점을 바꾸면 더 빨리 원하는 페이지를 찾을 수 있습니다.

전체 검색은 [주소모음·링크모음·사이트모음 통합 목록](/directory), 분야별 출발점은 [사이트 카테고리](/categories/)에서 확인하세요. 링크위키는 등록된 목적과 연결 주소를 소개하지만 공식 인증, 실시간 접속 상태, 서비스 안전성을 보증하지 않습니다.
